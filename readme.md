# Anurag Padhi · Portfolio

An interactive portfolio where visitors drive a small car through Anurag's professional journey. It's built on Bruno Simon's [folio-2025](https://github.com/brunosimon/folio-2025) (MIT).

It works **recruiter-first**. The name, studies, interests, highlights, contact links and the resume download render as plain HTML immediately. The 3D world loads afterwards in the background, and only on capable desktops. Phones and tablets get a lightweight mode with an optional "Drive through it in 3D" button.

## Setup

``` bash
npm install --force   # Install dependencies
npm run dev           # Serve at localhost:1234
npm run build         # Production build in dist/
npm run preview       # Serve the production build
```

Copy `.env.example` to `.env` (optional, the defaults work).

URL options: `?mode=3d` forces the 3D world, `?mode=lite` forces the lightweight mode, and `#debug` opens the debug panel.

## Editing content

See **[docs/UPDATING.md](docs/UPDATING.md)** for a step-by-step guide to updating after a resume change.

All text lives in `sources/data/`:

| File | What it controls |
| --- | --- |
| `portfolio.js` | Profile, experience, projects, education, certifications, achievements, skills, sections (all HTML panels) |
| `projects.js` | Items on the 3D Projects board |
| `lab.js` | Items on the 3D Education board |
| `social.js` | Interactive points around the statue (Skills & Contact area) |

The resume is served from `static/resume/Anurag-Padhi-Resume.pdf`. Replace that file to update it.

The board images in `static/projects/images` and `static/lab/images` are generated by `node scripts/portfolio-images.js`. Edit the list in that script and re-run it.

The career timeline stones (Experience area) are drawn at runtime from `careerLabels` in `sources/Game/World/Areas/CareerArea.js`.

## Map

| Location | Area in the scene | Content |
| --- | --- | --- |
| Home | `landing` | Name in 3D letters, "Portfolio map" kiosk, controls |
| Experience | `career` | Timeline stones + "My experience" point |
| Projects | `projects` | BioNex and Mitti Mantra board |
| Education | `lab` | Christ University, COIL and certifications board |
| Achievements | `achievements` | Opens the achievements panel |
| Skills & Contact | `social` | Email, LinkedIn, Call, Resume, Skills, Contact points |

The other theme-park areas were removed: circuit, bowling, cookie, toilet, altar, time machine, behind the scene, whispers, the easter and Black Friday events, and the music.

## Structure

- `sources/index.js` renders the portfolio layer, picks full 3D or lite mode, and lazy-loads the game.
- `sources/Portfolio/Portfolio.js` holds the nav bar, intro card and section panels, plus the bridge to the game (teleporting to areas).
- `sources/style/portfolio.styl` styles the portfolio layer, using the original palette and fonts.
- `sources/Game/` contains the original engine (Three.js WebGPU + Rapier physics), trimmed down.

Only compressed assets (`-compressed.glb`, `.ktx`) are kept in `static/`. The uncompressed Blender exports were removed to keep the site light.
